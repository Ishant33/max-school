# Disclosure document uploads

Store mandatory-disclosure PDFs in these folders:

- `uploads/disclosure/b/` for Documents & Information
- `uploads/disclosure/c/` for Results & Academics

Keep the filenames used by the links on `mandatory-disclosure.html` (for example, `b/1.pdf` and `c/1.pdf`). The public page will then show each document through its existing **View** link.
